# Content editing guide

Common edits:

- Business wording: edit the relevant `.html` page.
- Booking URL: `assets/js/site-config.js`.
- Colours and spacing: `assets/css/styles.css`.
- Logo files: `assets/img/`.
- Service area: search all files for `Coquitlam`.
- Email addresses: search all files for `@alitechgrid.com`.

Do not edit generated logo image files unless replacing them with approved production assets.
